Утверждена политика A:
- Обновление: apt update, apt-get --no-remove upgrade -y, контроль списка обновлений.
- Исправление зависимостей: apt-get --no-remove -f install -y.
- Автоматические dist-upgrade и autoremove исключены.
- Изменяющие операции требуют одноразового подтверждения.
- При ошибке дальнейшие команды не выполняются.

Ограничения:
- Блокировка не распространяется на внешние процессы APT/dpkg.
- Синхронный subprocess.run может задерживать обработку Telegram Update.
- --no-remove запрещает удаления, но не исключает изменение конфигурации
  или перезапуск служб при обновлении.
- Отсутствие необходимости удаления подтверждено симуляцией текущего
  состояния APT; реальные операции установки не тестировались.
