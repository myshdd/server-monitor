# Server Monitor — правила разработки

Версия: 1.0
Дата: 09.11.2026
Назначение: правила изменения, проверки и сопровождения Server Monitor.

## Проект

Server Monitor v3.
Компоненты: Python, Bash, Telegram Admin Bot, Telegram Monitor,
Fail2ban, Monit, cron, systemd и Docker.

Рабочее окружение: Ubuntu Linux.
Основная документация аудита: doc/plan.md.
Реестры: doc/test_registry.md и doc/remarks_registry.md.

## Git

- release/v2 сохраняет исходную версию 2.
- main предназначена для версии 3.
- Изменения разрабатываются в feature-ветках.
- Не изменять release/v2.
- Не выполнять git reset --hard или force push без согласования.
- Перед коммитом проверять git diff и состав индекса.
- Не включать рабочие данные, журналы, секреты и резервные копии.

## Безопасность

- config/secrets.json содержит действующие токены и исключён из Git.
- Не читать и не выводить значения секретов без необходимости.
- В диагностических результатах заменять секреты на REDACTED.
- Не изменять рабочие конфигурации без отдельного согласования.
- Не выполнять обновление пакетов, перезагрузку, выключение сервера,
  изменение firewall или управление контейнерами при тестировании.

## Разработка

- Принцип минимальных изменений.
- До изменения изучить существующую реализацию.
- Не выполнять рефакторинг несвязанных подсистем.
- Делать резервную копию перед изменениями действующего кода.
- Не создавать коммиты автоматически.

## Проверки

- Python: компиляция через py_compile и изолированные тесты.
- Bash: проверка синтаксиса через bash -n.
- Проверять git diff --check для изменённых участков.
- Системные операции подменять Mock в функциональных тестах.
- После активации проверять systemd, журналы и связанные службы.
- Результаты фиксировать в doc/test_registry.md.
- Замечания фиксировать в doc/remarks_registry.md.
- Статусы этапов обновлять in-place в doc/plan.md.

## Документация

- Сохранять существующие имена документов.
- Указывать версию, дату и назначение документа.
- BUILD-отчёты являются неизменяемыми снимками.
- Не дублировать сведения между документами.
